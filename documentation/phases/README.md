# Phase designs

Each phase gets one design file here, written and agreed before coding starts: `phase-0-foundation.md`, `phase-1-fact-check-mvp.md`, and so on.

Each phase file contains:

1. **Goal** in plain English.
2. **Design:** structure, components, data flow, with a diagram.
3. **Decisions** made (each also recorded as an ADR in `../decisions/`).
4. **Done when:** the checks that close the phase.
5. **Outcome** (filled in at the end): what was built, the numbers, what changed from the plan.
